Status Bar Preview

Type in the textarea below to see the status bar update in real-time. The status bar shows document statistics and useful information for content creators.

Status Bar Features

Words: Total word count - essential for writers tracking document length

Characters: Total character count including spaces

Lines: Number of lines in the document

Reading Time: Estimated reading time based on 200 words per minute

Headings: Number of markdown headings (document structure indicator)

Links: Number of links in the document

PDF Pages: Estimated pages when exported to PDF (based on ~500 words per page)

Last Saved: Auto-save status indicator

Selection: When text is selected, shows selected word/character count
