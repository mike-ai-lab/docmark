# Basic Usage

Learn the fundamentals of using the application.

## Getting Started

After installation, you can start using the application immediately.

## Basic Operations

### Creating a Document
1. Click the "New Document" button
2. Enter your content
3. Save your work

### Editing
- Use the editor on the left
- See live preview on the right
- Changes are auto-saved

## Tips

- Use keyboard shortcuts for faster editing
- Enable dark mode for comfortable viewing
- Check the FAQ for common questions
