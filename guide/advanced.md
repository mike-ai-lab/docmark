# Advanced Features

Explore advanced capabilities and features.

## Documentation Mode

Upload ZIP files containing multiple markdown documents for organized documentation.

### Features
- Multi-file navigation
- Table of contents
- Search functionality
- Custom themes

## Export Options

Export your work in multiple formats:
- PDF with custom styling
- Standalone HTML
- Markdown files

## Customization

### Themes
Choose from 8 professional themes:
- GitHub
- GitBook
- VSCode
- Notion
- Medium
- LaTeX
- Minimal
- Typewriter

### Configuration
Use `book.json` to customize your documentation site.
