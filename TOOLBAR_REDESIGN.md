### Main Buttons (Always Visible)
Just click them - they work immediately

### Dropdown Menus

3. Click your choice
4. Menu closes automatically

### Keyboard Shortcuts
- Ctrl+Z / Cmd+Z: Undo (also works with button)
- Ctrl+C / Cmd+C: Copy
- Ctrl+V / Cmd+V: Paste

## 🐛 Troubleshooting

**Dropdown doesn't appear?**
- Make sure you're hovering over the button
- Wait a moment for the animation

**Undo doesn't work?**
- Make sure editor has focus
- Try Ctrl+Z / Cmd+Z keyboard shortcut

**Buttons overlapping?**
- Refresh the page
- Clear browser cache
