## Common Issues:

### Browser Blocking Downloads
- Check if browser shows a blocked download notification
- Look for a shield icon or warning in the address bar
- Check browser's popup blocker settings

### Download Manager
- Some browsers have a download manager that intercepts downloads
- Press `Ctrl + J` in Chrome/Edge to open download history
- Check if the file is listed there

### Antivirus Software
- Some antivirus programs scan downloads and may delay them
- Check your antivirus quarantine folder
