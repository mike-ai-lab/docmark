🚀 Usage Examples

Example 1: Direct HTML Writing
Write HTML directly in the markdown editor and it will render in the preview.
<div style="background: #f0f9ff; padding: 20px;">
  <h3>Custom Block</h3>
  <p>This renders fully!</p>
</div>
Example 2: Paste HTML Content
Copy HTML from any webpage → Paste in editor → Choose "Keep as HTML" → Renders perfectly!
Example 3: Mixed Content
Combine markdown syntax with HTML elements in the same document for maximum flexibility.

🔒 Security Features

  • Script Blocking: All <script> tags are automatically removed
  • Event Handler Stripping: onclick, onerror, and similar attributes are blocked
  • Safe Defaults: Only explicitly allowed tags and attributes pass through
  • Content Preservation: Safe content is kept even if dangerous tags are removed
  • XSS Prevention: DOMPurify prevents cross-site scripting attacks
