# Paper Layout - User Guide

## Quick Start

1. **Activate Paper Layout**: Click "Web Layout" in the status bar (bottom)
2. **Controls Appear**: Compact control bar appears at top of preview
3. **Choose Mode**: Click the mode button to switch between Flow and Pages

## Control Bar Overview

```
┌─────────────────────────────────────────────────┐
│  [-] 100% [+]  │  [←] 1/3 [→]  │  [Flow/Pages] │
└─────────────────────────────────────────────────┘
     Zoom            Navigation        Mode Toggle
```

## Zoom Controls

### Zoom In/Out
- **Click [+]**: Zoom in (up to 200%)
- **Click [-]**: Zoom out (down to 50%)
- **Display**: Shows current zoom percentage

### Tips
- Zoom level is saved automatically
- Works in both Flow and Pages mode
- Smooth zoom transitions

## Navigation Modes

### Flow Mode (Default)
- **What**: All pages visible, scroll normally
- **Best For**: Reading through entire document
- **Navigation**: Scroll with mouse or trackpad
- **Arrows**: Hidden (not needed)

### Pages Mode
- **What**: One page at a time, like a book
- **Best For**: Focused reading, presentations
- **Navigation**: Arrow buttons or keyboard
- **Arrows**: Visible and active

## Page Navigation (Pages Mode Only)

### Mouse Navigation
- **Click [←]**: Go to previous page
- **Click [→]**: Go to next page
- **Page Counter**: Shows current page / total pages

### Keyboard Navigation
- **Arrow Left** or **Arrow Up**: Previous page
- **Arrow Right** or **Arrow Down**: Next page

### Tips
- First page: Left arrow is disabled
- Last page: Right arrow is disabled
- Page counter updates automatically

## Switching Modes

### To Pages Mode
1. Click the mode button (shows "Flow")
2. Button changes to show "Pages"
3. Navigation arrows appear
4. Only one page visible

### To Flow Mode
1. Click the mode button (shows "Pages")
2. Button changes to show "Flow"
3. Navigation arrows disappear
4. All pages visible again

## Status Bar

The status bar (bottom of screen) shows:
- **Layout Mode**: "Paper Layout" or "Web Layout"
- **Click It**: Toggle paper layout on/off

## Page Content

### What Breaks Across Pages
- ✅ Paragraphs (can split naturally)
- ✅ Lists (can split naturally)
- ✅ Tables (can split naturally)

### What Doesn't Break
- ❌ Code blocks (stay intact)
- ❌ Headings (stay with content)

### Result
- Pages are filled efficiently
- No large empty spaces
- Natural reading flow

## Tips & Tricks

### For Reading
1. Use **Pages Mode** for focused reading
2. Use **Arrow Keys** for quick navigation
3. Adjust **Zoom** for comfortable reading size

### For Editing
1. Use **Flow Mode** to see all content
2. Switch to **Pages Mode** to check page breaks
3. Content re-paginates automatically as you type

### For Presenting
1. Activate **Pages Mode**
2. Use **Arrow Keys** to navigate
3. Adjust **Zoom** to fit screen

### For Exporting
1. Check layout in **Paper Layout**
2. Pages in preview match PDF export
3. Export to PDF when ready

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Previous Page | ← or ↑ |
| Next Page | → or ↓ |
| Toggle Layout | Click status bar |

## Troubleshooting

### Controls Not Visible
- **Solution**: Click "Web Layout" in status bar to activate

### Navigation Arrows Hidden
- **Solution**: Click mode button to switch to "Pages" mode

### Keyboard Navigation Not Working
- **Solution**: Make sure you're in Pages mode (not Flow mode)

### Pages Look Wrong
- **Solution**: Content re-paginates automatically, wait a moment

### Zoom Too Small/Large
- **Solution**: Use zoom controls or adjust to comfortable level

## Best Practices

### Document Structure
- Use headings to organize content
- Keep code blocks reasonable size
- Tables will break naturally if needed

### Navigation
- Use Flow mode for overview
- Use Pages mode for detailed reading
- Switch modes as needed

### Zoom
- 100% is standard reading size
- Increase for presentations
- Decrease to see more pages

## Summary

The paper layout system provides a flexible way to view your markdown content as formatted pages, with both continuous flow and page-by-page navigation options. The compact controls stay out of your way while providing all the functionality you need.

Enjoy your enhanced reading and editing experience!
