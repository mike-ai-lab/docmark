# Code Paste Window - Quick Start Guide 🚀

## What Is It?

A **minimizable floating window** that lets you paste code directly and see it render instantly—no file saving needed!

---

## Where Is It?

Look for the **code icon `<>`** in the **top-right header** (next to Settings, Help, etc.)

---

## How to Use

### 1️⃣ Open the Window
- **Click** the code icon `<>` in the header
- **Or press** `Ctrl+Shift+P`

### 2️⃣ Paste Your Code
- Click in the textarea
- Paste HTML, CSS, or JavaScript
- **It auto-renders automatically!**

### 3️⃣ See the Preview
- Preview appears below the textarea
- Shows rendered HTML or code output

### 4️⃣ Manage the Window

| Button | What It Does |
|--------|-------------|
| **−** (Minimize) | Collapse window, button turns BLUE |
| **×** (Close) | Hide window completely |
| **Render** | Manually render code |
| **Clear** | Clear textarea and preview |

---

## Button States

### 🔘 Normal (Window Open)
- Gray button
- Window is expanded and visible

### 🔵 Blue Button (Minimized)
- **BLUE background** = Window is minimized
- Click to expand it back

### ⚪ Gray Button (Closed)
- Window is hidden
- Click to reopen it

---

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+P` | Toggle minimize/expand/close |
| `Ctrl+A` | Select all code |
| `Ctrl+C` | Copy code |
| `Ctrl+V` | Paste code (auto-renders) |

---

## Example: Paste HTML

```html
<div style="background: #3b82f6; color: white; padding: 20px; border-radius: 8px;">
  <h1>Hello World!</h1>
  <p>This renders instantly!</p>
</div>
```

1. Paste this into the textarea
2. It renders automatically
3. See the blue box with text in the preview

## Troubleshooting

**Q: I can't see the button!**
- Look in the **top-right header** next to Settings and Help
- It's the code icon `<>`

**Q: Code won't render**
- Make sure it's valid HTML/CSS/JavaScript
- Check the error message in the preview

**Q: Where's my code when I close the window?**
- Code is only stored while the window is open
- It's not saved to a file (that's the point!)

**Q: Can I use it with external scripts?**
- External scripts are blocked for security
- Use inline `<script>` tags instead
