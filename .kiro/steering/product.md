# Product Overview

DocMark is a browser-based markdown editor with real-time preview and professional export capabilities. No installation or backend required.

## Core Value Proposition

- Real-time bidirectional sync between editor and preview
- Professional PDF/HTML export with multiple theme options
- Advanced features: PDF import, table detection, YAML front matter, TOC generation
- Media handling: drag-and-drop embedding with base64 conversion
- Validation and beautification tools for markdown quality

## Key Features

- Monaco Editor integration (VS Code editor engine)
- Multiple preview themes (GitHub, GitBook, VSCode, Notion, Medium, LaTeX, Minimal, Typewriter)
- PDF generation via jsPDF and Puppeteer
- PDF import with intelligent table detection
- AI Assistant integration (Mofu)
- Documentation mode for multi-file projects
- HTML Inspector for visual editing (experimental)
- Auto-save to localStorage
- 50-step undo/redo history

## Target Users

Developers, technical writers, content creators, students, and anyone needing a feature-rich markdown editor without complexity.
