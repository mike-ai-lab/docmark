📄 Approach 1: Per-Page Processing

Method: Loop through each .a4-page div separately, process its content, then add a new PDF page.

Pros:
  • WYSIWYG - Exact pagination as shown
  • Respects existing page breaks
  • Simple logic - one page = one PDF page
Cons:
  • May have orphan lines if pagination is off
  • Requires accurate pre-pagination
