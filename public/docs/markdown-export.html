Markdown Export

Save your markdown source as a .md file for use in other tools and platforms.

Why Export Markdown

  • Version Control - Commit to Git repositories
  • Portability - Use in any markdown editor
  • Publishing - Upload to GitHub, GitLab, etc.
  • Backup - Save your work locally

What's Included

The exported file contains:

  • All markdown source code
  • YAML front matter (if present)
  • Comments and metadata
  • Exactly as written in the editor

How to Export

Click Export → Export Markdown. The file downloads with a .md extension.
