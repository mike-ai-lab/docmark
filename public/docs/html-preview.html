HTML Preview & CSS Support

DocMark supports full HTML documents with custom CSS styling, perfect for web designers and developers.

HTML Preview Mode

DocMark automatically detects full HTML documents and renders them in a dedicated preview mode:

  • Paste or import complete HTML documents
  • Full-screen preview with live rendering
  • Support for JavaScript and interactive elements
  • Automatic CSS injection and linking

How HTML is Detected

DocMark recognizes HTML documents by checking for:

  • <!DOCTYPE html> declaration
  • <html> tag at the start of content

When detected, the preview automatically switches to HTML mode.

CSS Support

DocMark provides multiple ways to include CSS with your HTML:

Upload CSS Files

Use the CSS upload button (blue icon) in the toolbar to upload external CSS files. The CSS will be automatically injected into your HTML preview.

CSS via Comments

Reference CSS files using HTML comments in your document:

<!-- CSS: path/to/styles.css -->

DocMark will automatically link these CSS files to your HTML.

Inline CSS

Include <style> tags directly in your HTML:

<style>
  body { font-family: Arial, sans-serif; }
  h1 { color: #333; }
</style>

Importing HTML Files

You can import HTML files directly:

  1. Click Import

    Use the Import button in the toolbar

  2. Select HTML File

    Choose your HTML file from your computer

  3. Upload CSS (if needed)

    If your HTML references external CSS, use the CSS upload button

Tip

If your HTML file references a CSS file, DocMark will notify you to upload it for proper styling.

Supported HTML Features

  • All standard HTML5 elements
  • CSS styling and animations
  • JavaScript execution (sandboxed for security)
  • Forms and interactive elements
  • Media elements (images, video, audio)
  • Embedded content (iframes, etc.)

Security

HTML preview runs in a sandboxed iframe with restricted permissions:

  • Scripts run in isolated context
  • No access to your local files
  • No access to other websites' data
  • Dangerous content is sanitized

Use Cases

  • Web Design - Preview and refine web designs
  • Email Templates - Design and test email HTML
  • Documentation - Create interactive documentation
  • Prototyping - Quick prototyping with HTML/CSS/JS
