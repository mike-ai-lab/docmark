Themes & Styles

Customize the appearance of your preview with multiple professional themes and dark mode support.

Preview Styles

Choose from several professionally designed styles:

  • GitHub Light/Dark - Classic GitHub markdown styling
  • GitBook - Clean documentation style
  • VSCode - Familiar editor appearance
  • Medium - Blog-style formatting
  • Minimal - Clean and simple
  • Notion - Modern workspace style
  • LaTeX - Academic paper formatting

Dark Mode

Toggle between light and dark themes for comfortable editing in any lighting condition. Dark mode applies to both the editor and preview.

Layout Modes

  • Web Layout - Optimized for screen reading
  • Paper Layout - A4/Letter page format for print preview
