Markdown Validation

Catch markdown errors before export with DocMark's validation wizard.

What It Checks

The validation tool scans your document for common issues:

  • Broken Links - Invalid URLs or missing anchors
  • Missing Images - Image references that don't resolve
  • Syntax Errors - Malformed markdown syntax
  • Heading Structure - Skipped heading levels
  • List Formatting - Inconsistent list markers

How to Use

  1. Click Validate

    Find the Validate button in the toolbar

  2. Review Issues

    See a list of all detected problems

  3. Fix Errors

    Click any issue to jump to its location

  4. Re-validate

    Run validation again to confirm fixes
