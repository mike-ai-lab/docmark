Paper Layout

Preview your document in a realistic paper format with pagination, perfect for preparing documents for print or PDF export.

What is Paper Layout?

Paper Layout displays your markdown as it would appear on printed pages. This helps you:

  • See exactly how content will break across pages
  • Adjust formatting before PDF export
  • Ensure proper page breaks and spacing
  • Preview professional document layout

Enabling Paper Layout

Click the Paper Layout toggle button in the toolbar to switch between web and paper view.

Features

  • Realistic Pages - Standard letter or A4 size pages
  • Pagination - Automatic page breaks
  • Page Navigation - Jump between pages
  • Zoom Control - Adjust zoom level for better viewing
  • Live Updates - Changes update in real-time

Page Navigation

When in Paper Layout mode, use the page navigation controls:

  • Previous/Next - Navigate between pages
  • Page Counter - Shows current page and total pages
  • Jump to Page - Enter page number to jump directly

Zoom Control

Adjust the zoom level to see more or less of the page:

  • Zoom In - See more detail
  • Zoom Out - See full page
  • Fit to Width - Adjust to window width
  • Fit to Page - Show entire page

Best Practices

  • Use Paper Layout before exporting to PDF to check formatting
  • Adjust content if pages break awkwardly
  • Use page breaks in markdown to control pagination
  • Check all pages before final export
