📄 PDF Import

Import and convert PDF documents to editable Markdown with automatic table detection.

Overview

The PDF Import feature allows you to extract content from PDF files and convert it to Markdown format. It intelligently detects document structure including headings, paragraphs, lists, and tables.

✨ Key Features:
  • Automatic table detection and conversion
  • Structure preservation (headings, lists, paragraphs)
  • Multi-page PDF support
  • Preview before insertion
  • No file size limits

How to Import a PDF

Step 1: Open PDF Import

Click the PDF icon (📄) button in the top-right header toolbar.

Step 2: Select PDF File

Choose a PDF file from your computer. Supported formats:

  • Text-based PDFs (preferred)
  • PDFs with tables and structured content
  • Multi-page documents

Step 3: Preview Content

The extracted content will be displayed in a preview modal. Review the conversion quality before inserting.

Step 4: Insert into Editor

Click "Insert" to add the converted Markdown to your document at the current cursor position.

⚠️ Limitations

  • Images: Not yet supported (coming soon)
  • Complex tables: Merged cells may not convert perfectly
  • Multi-column layouts: Converted to single column
  • Scanned PDFs: Text extraction may be limited

Table Detection

The PDF import feature uses intelligent spatial analysis to detect tables in your PDF:

How It Works

  1. Text Position Analysis: Analyzes X/Y coordinates of text
  2. Column Detection: Groups text into columns based on alignment
  3. Row Grouping: Identifies rows by vertical position
  4. Markdown Conversion: Generates proper Markdown table syntax

Best Results

For optimal table detection:

  • Use PDFs with clear column spacing
  • Avoid PDFs with heavily merged cells
  • Simple table layouts work best

Example Output:

| Column 1 | Column 2 | Column 3 |
| :--- | :--- | :--- |
| Data 1 | Data 2 | Data 3 |
| Data 4 | Data 5 | Data 6 |

Tips for Best Results

📋 Before Importing

  • Use text-based PDFs (not scanned images)
  • Ensure PDF has selectable text
  • Simple layouts convert better than complex ones

✏️ After Importing

  • Review the converted content in preview
  • Check table alignment and adjust if needed
  • Verify heading hierarchy
  • Add missing formatting manually

🔧 Troubleshooting

Issue Solution
No text extracted PDF may be scanned/image-based. Try OCR software first.

FAQ

Can I import scanned PDFs?

Scanned PDFs (images) have limited support. For best results, use OCR software to convert scanned PDFs to text-based PDFs first.

Why are my tables misaligned?

Tables with multi-line cells or wrapped text may not align perfectly. The feature detects tables by text position, not visual borders. You can manually adjust the Markdown table after import.

Can I import images from PDFs?

Image extraction is not yet supported but is planned for a future update.

Is there a file size limit?

No hard limit, but very large PDFs (100+ pages) may take longer to process.

Can I import password-protected PDFs?

Not currently supported. Remove password protection before importing.
