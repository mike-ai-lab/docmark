AI Assistant

Integrate with AI models like ChatGPT, Claude, and Gemini to enhance your writing and content creation directly within DocMark.

Getting Started

The AI Assistant panel is accessible from the toolbar. To use it, you'll need to configure an AI provider with your API key.

Setup Your API Key

  1. Open AI Settings

    Click the AI Assistant icon in the toolbar to open the panel

  2. Add API Key

    Go to Settings and enter your API key for your chosen provider (OpenAI, Anthropic, Google, etc.)

  3. Test Connection

    Click "Test API Key" to verify your credentials are valid

Security Note

Your API keys are stored locally in your browser and never sent to our servers. All communication is direct with the AI provider.

Quick Actions

Use quick action buttons to instantly improve your content:

  • Improve Writing - Enhance clarity and readability
  • Fix Grammar - Correct spelling and grammar errors
  • Make Shorter - Condense content while preserving meaning
  • Make Longer - Expand content with more detail
  • Simplify - Use simpler language and shorter sentences
  • Professional Tone - Adjust tone for business context
  • Casual Tone - Make content more conversational

Chat Interface

For more complex requests, use the chat interface to have a conversation with the AI:

  1. Select Text (Optional)

    Highlight text in the editor to include it in your prompt

  2. Type Your Request

    Ask the AI to help with writing, editing, brainstorming, or any other task

  3. Insert Response

    Click "Insert" to add the AI's response to your document

Supported AI Providers

  • OpenAI - ChatGPT (GPT-4, GPT-3.5)
  • Anthropic - Claude
  • Google - Gemini

Each provider requires its own API key, which you can obtain from their respective websites.

Best Practices

  • Be specific in your requests for better results
  • Use quick actions for common tasks to save time
  • Review AI-generated content before finalizing
  • Combine AI assistance with your own editing for best results
  • Use the chat interface for complex or creative tasks
