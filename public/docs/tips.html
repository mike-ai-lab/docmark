Tips & Best Practices

Get the most out of DocMark with these productivity tips and best practices.

Writing Tips

  • Use Headings Hierarchically - Don't skip heading levels (H1 → H2 → H3)
  • Add Blank Lines - Separate paragraphs and sections with blank lines
  • Keep Lines Short - Aim for 80-100 characters per line for readability
  • Use Lists - Break up long paragraphs with bullet points

Working with AI Content

  • Ask for Markdown - Tell AI models to output in markdown format
  • Beautify After Paste - Use the Beautify tool to clean up AI-generated markdown
  • Validate Before Export - Run validation to catch any formatting issues

Productivity Hacks

  • Use Keyboard Shortcuts - Learn common shortcuts to speed up editing
  • Enable Auto-Save - Your work is automatically saved to localStorage
  • Use TOC for Navigation - Jump to sections quickly in long documents
  • Preview Different Styles - Try multiple themes before exporting

Export Tips

  • Validate First - Always validate before exporting to PDF
  • Check Preview - Use Paper Layout to see how PDF will look
  • Add Metadata - Use YAML front matter for professional PDFs
  • Test Fonts - Preview with different font settings
