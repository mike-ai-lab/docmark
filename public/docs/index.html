Welcome to DocMark

DocMark is a powerful, browser-based markdown editor with real-time preview, advanced formatting tools, and professional export capabilities.

What is DocMark?

DocMark transforms the way you work with markdown by providing instant visual feedback, intelligent formatting assistance, and professional export options. Whether you're writing documentation, creating reports, or drafting content, you'll see exactly how your document looks without switching between edit and preview modes.

Key Benefits

  • No Installation Required - Works entirely in your browser
  • Real-Time Preview - See changes instantly as you type
  • Smart Validation - Catch markdown errors before export
  • One-Click Beautify - Professional formatting automatically
  • Media Support - Drag & drop images and videos
  • Multiple Export Formats - PDF, HTML, and Markdown
  • Auto-Save - Never lose your work
  • Completely Free - No limitations or sign-up required

Quick Start

Get started with DocMark in three simple steps:

Step 1: Start Writing
Type or paste your markdown content into the editor on the left. The preview updates in real-time on the right.
Step 2: Format & Validate
Use the Beautify button to clean up formatting, or enable Validation to catch errors automatically.
Step 3: Export
Click Export to save as PDF, HTML, or Markdown. Your document is ready to share!

Interface Overview

DocMark's interface is divided into several key areas:

Header Bar

Contains all main controls:

  • File Operations - New, Reset, Import, Export
  • Editing Tools - Undo, Redo, Beautify
  • Insert Buttons - Header, Footer, Break, Image, Photo
  • Settings - Theme, Style, Layout options

Editor Pane

Monaco Editor with syntax highlighting, autocomplete, and multi-cursor support.

Preview Pane

Live rendered output with clickable navigation and scroll sync.

Status Bar

Shows document statistics: word count, character count, reading time, and estimated PDF pages.

Editor Features

The editor is powered by Monaco Editor (the same technology behind VS Code) and provides:

  • Syntax Highlighting - Markdown syntax is color-coded for easy reading
  • Autocomplete - Intelligent suggestions as you type
  • Multi-Cursor Editing - Hold Alt/Option and click to create multiple cursors
  • Find & Replace - Press Ctrl+F (Cmd+F on Mac) to search
  • 50-Step Undo/Redo - Comprehensive undo history with Ctrl+Z and Ctrl+Y

Live Preview

The preview pane shows your formatted document in real-time with several interactive features:

  • Click to Navigate - Click any element in the preview to jump to its source
  • Scroll Synchronization - Scroll in either pane and the other follows
  • Cursor Highlighting - The preview highlights the section corresponding to your cursor

Synchronization

DocMark keeps your editor and preview perfectly aligned:

  • Bidirectional Scroll Sync - Scroll in the editor, and the preview follows
  • Cursor Sync - Move your cursor in the editor, and the corresponding section highlights

Both features can be toggled on/off in the settings menu.

Themes & Styles

Choose from three professional preview styles:

  • GitHub Style - Clean, modern style perfect for technical documentation
  • GitBook Style - Elegant and spacious, designed for long-form documentation
  • VSCode Style - Developer-friendly aesthetics for code-heavy documents

Dark Mode: Toggle dark mode for comfortable late-night writing sessions.

Markdown Validation

Real-time validation catches common markdown issues:

  • Missing blank lines around headings
  • Missing blank lines around lists
  • Missing blank lines around code blocks
  • Inconsistent list markers
  • Malformed links and images
  • Table formatting issues

Auto-Fix: Click the "Auto-fix" link to automatically correct all detected issues.

Export Validation Report: Export a markdown file listing all validation issues for review.

Beautify & Format

Professional markdown formatting with a single click:

  • Consistent heading spacing
  • Proper list indentation
  • Table alignment
  • Code block formatting
  • Blank line normalization

Diff View: Before applying changes, review a visual diff showing additions and removals.

Media Handling

DocMark makes it easy to work with images and videos:

  • Drag & Drop: Drag images or videos directly into the editor for automatic base64 embedding
  • Supported Formats: JPG, PNG, GIF, WebP, BMP, MP4, WebM, OGG, MOV
  • Media Context Menu: Right-click any image or video in the preview to move it up or down
  • Smart Folding: Base64 content is automatically folded in the editor for cleaner viewing

Table of Contents

  • Updates in real-time as you write
  • Click any heading to jump to that section
  • Included automatically in PDF exports
  • Toggle visibility in settings

Keyboard Shortcuts

  • Undo: Ctrl+Z (Cmd+Z on Mac)
  • Redo: Ctrl+Y (Cmd+Shift+Z on Mac)
  • Find: Ctrl+F (Cmd+F on Mac)
  • Replace: Ctrl+H (Cmd+Option+F on Mac)
  • Multi-cursor: Alt+Click (Option+Click on Mac)

Tips & Best Practices

For Best Results

  • Use blank lines to separate sections
  • Enable validation to catch errors early
  • Run Beautify before exporting
  • Use YAML front matter for professional PDFs
  • Test your document in different preview styles

Working with AI Content

  • Paste AI-generated markdown directly
  • Use Beautify to clean up formatting
  • Enable validation to catch AI errors
  • Review the diff before applying changes
