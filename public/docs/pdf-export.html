PDF Export

Generate professional PDFs with fine-grained control over fonts, layout, and metadata.

Basic Export

  1. Click Export

    Find the Export button in the toolbar

  2. Select PDF

    Choose "Export PDF" from the dropdown

  3. Download

    Your PDF downloads automatically

Font Settings

Customize fonts for different elements:

  • Body Font - Main text font and size
  • Heading Fonts - Individual fonts for H1-H6
  • Code Font - Monospace font for code blocks
  • Line Height - Spacing between lines

Document Metadata

Add metadata using YAML front matter:

---
title: My Document
author: Your Name
date: 2026-02-17
---

Metadata appears in PDF properties and can be used for headers/footers.

Headers & Footers

Configure custom headers and footers with dynamic content like page numbers, title, and date.
