Media Handling

Add images and videos to your documents with drag-and-drop simplicity.

Images

Add images using standard markdown syntax:

![Alt text](image-url.jpg)

Supported formats: JPG, PNG, GIF, WebP, SVG

Videos

Embed videos using HTML video tags or platform-specific embed codes (YouTube, Vimeo, etc.)

Drag & Drop

Drag image files directly into the editor to automatically insert them with proper markdown syntax.
