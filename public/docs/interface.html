Interface Overview

DocMark's interface is designed for maximum productivity with a clean, distraction-free layout.

Main Components

Header Toolbar

The top toolbar contains all essential controls:

  • File Operations - New, Open, Save, Import
  • Export Options - PDF, HTML, Markdown
  • View Controls - Layout, Theme, Style selector
  • Tools - Validation, Beautify, TOC, Help

Editor Pane

The left pane features Monaco Editor with:

  • Syntax highlighting for markdown
  • Line numbers and code folding
  • Auto-completion and snippets
  • Find and replace functionality

Preview Pane

The right pane shows your rendered document with:

  • Real-time updates as you type
  • Multiple style themes
  • Click-to-navigate to source
  • Scroll synchronization

Layout Options

DocMark supports multiple layout configurations:

  • Side-by-Side - Editor on left, preview on right (default)
  • Stacked - Editor on top, preview on bottom
  • Editor Only - Full-width editor for focused writing
  • Preview Only - Full-width preview for presentation

Resize panes by dragging the divider between them.
