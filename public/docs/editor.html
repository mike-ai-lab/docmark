Editor Features

DocMark uses Monaco Editor, the same powerful editor that powers VS Code.

Syntax Highlighting

Markdown syntax is automatically highlighted with distinct colors for:

  • Headings (# ## ###)
  • Bold and italic text
  • Links and images
  • Code blocks and inline code
  • Lists and blockquotes

Editing Features

Auto-Completion

Start typing markdown syntax and get intelligent suggestions.

Multi-Cursor Editing

Hold Alt/Option and click to place multiple cursors for simultaneous editing.

Find & Replace

Use Ctrl+F (Cmd+F on Mac) to search, Ctrl+H for find and replace.

Code Folding

Collapse sections of your document for better navigation.

Clipboard Operations

Standard clipboard operations work seamlessly:

  • Copy - Ctrl+C / Cmd+C
  • Cut - Ctrl+X / Cmd+X
  • Paste - Ctrl+V / Cmd+V
  • Paste from AI - Works perfectly with ChatGPT, Claude, etc.
