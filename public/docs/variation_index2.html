Quick Start

Get started with DocMark in three simple steps. No registration, no setup required.

Step 1: Write or Paste Markdown

Open DocMark and start typing in the editor pane on the left. You can also paste markdown content from any source:

  • AI models (ChatGPT, Claude, Gemini)
  • Existing markdown files
  • Code documentation
Tip: When working with AI models, ask them to output in markdown format for best results.

Step 2: Preview in Real-Time

As you type, the preview pane on the right updates instantly. You'll see your formatted document exactly as it will appear in the final PDF.

Preview Features

  • Real-time rendering as you type
  • Toggle between web and paper layout

Step 3: Export to PDF

When you're ready, export your document to PDF:

  1. Click Export

    Find the Export button in the toolbar

  2. Select Export PDF

    Choose "Export PDF" from the dropdown menu

  3. Download

    Your professionally formatted PDF downloads automatically
