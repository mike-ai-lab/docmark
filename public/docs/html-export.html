HTML Export

Export your document as a standalone HTML file with embedded styles.

What You Get

HTML export creates a single, self-contained file with:

  • Complete HTML5 document structure
  • Embedded CSS styles from your chosen theme
  • All formatting preserved
  • No external dependencies

Use Cases

  • Web Publishing - Upload directly to your website
  • Email - Send formatted documents via email
  • Archiving - Save documents with formatting intact
  • Further Editing - Open in HTML editors

How to Export

Click Export → Export HTML. The file downloads with your document title as the filename.
